A screen for the gap between downloaded and installed.

The timer already fetched the new versions. You install them later, in the foreground. The TUI shows that gap honestly: a static prefetch behind you, a ghost install ahead, and one live phase only while something is actually running.

01

Two phases. One tree.

A package is never one state. The tree keeps the dimensions separate: the prefetch result is static badges on each node, the install is a ghost branch, and only a captured fetch animates. Cached nodes never move.

Past · completed by the timer

static Prefetch

  • Cache files, build artifacts, timestamps.
  • Evidence comes from the CacheDir scan and the aurto repo.
  • Cached nodes never animate. A finished download must not look live.
  • Unknown is a value. A missing fact says why.
mtime or last fetch time, never an invented start

Future, then live · started by you

ghost Install

  • The install is a ghost branch until you press i.
  • No ETA. The attached install is plan and result, not a fake live build.
  • The captured fetch is the only animated phase.
  • Failure freezes the tree, downstream is blocked, repair is specific.
no invented progress; attached install is not animated
ready 2 = 2 cached + 0 built · stale 0 · missing 0 · build-pending 1 partial 0 · failed 0 · unknown 0 · held 0

Borrowed, not beaten: the dependency tree (a graph drawn as a tree), phase glyphs, counters and Σ are nom's. The design does not try to out-do its live build. The difference is the prefetch state on the same tree, and the honest ghost install.

What actually moves a node

No timer. No synthetic percentage. A row changes only when an observation proves a transition. The 60s refresh re-reads static facts; it is not animation.

Live where it is real: v1 animates the captured fetch. The AUR build badge is static from the aurto repo; a live build tree needs a captured build action that owns makepkg, not v1. Not live: the attached yay -Syuu install. It is plan and result, because it owns the terminal and keeps the PKGBUILD review.

A frontier, not a queue: the ready set holds every node whose required edges are satisfied. Parallel roots run together; a join waits for all of them. The view preserves that partial order and never invents one global sequence. docs/ANIMATION.md has the formal model and worked diamond and two-root examples.

03

What a terminal can and cannot do.

This is the correction. A terminal is not a canvas. It is a grid of cells whose width, glyph coverage, color depth and input semantics belong to the emulator, the font, the multiplexer and the locale. The design only promises what it can prove, and says so when it cannot.

Guaranteed

The floor

ASCII in a monospaced font. Cursor addressing, alternate screen, raw mode, resize, 16 ANSI colors, arrow keys, Enter, Esc, Tab, Backspace.

Conditional

Depends on the terminal

Truecolor, Unicode width, box drawing, braille, bold/dim, mouse, clipboard, OSC 8 links, synchronized output, bracketed paste.

Not available

Never promise these

Pixels, alpha, fonts, images, curves, sub-cell text, a guaranteed frame rate, scrollback under the alternate screen, sound.

Hostile input

Text is not safe

Package metadata can contain ESC, OSC, bidi controls and control bytes. Rendering it raw can move the cursor, set the title or write the clipboard.

1. A grid, not a canvas

geometry

You cannot draw curves, gradients, alpha, or place text between cells. A cell is taller than it is wide, roughly 1:2.

Response: the tree is a forest on integer cells, drawn with tree lines. The optional timeline is a layered DAG; braille gives 2×4 subcells and only appears there. At 120×40 the tree is still a viewport, not the whole dependency graph. No physics, no curves.

2. Width is a guess

Unicode

You cannot know from inside the app whether ▲ takes one cell or two. Emoji take two, combining marks take zero, and CJK terminals disagree.

Response: measure every user string with unicode-width, pad by measured width, keep one spare column at the right edge, never split a grapheme. Box drawing is Tier B. A CJK ambiguous-width locale gets an --ascii hint, not a broken frame.

3. Glyph coverage is not knowable

fonts

Braille, quadrant blocks, ☑, ◆, ◐ and ✖ may be missing, substituted or double-width. Nerd Font glyphs are a private contract.

Response: three tiers. Tier A is ASCII and always works. Tier B is the shipped Unicode set. Tier C is the optional timeline's braille and block view. No Nerd Fonts, no emoji, no variation selectors, no zero-width joiners.

4. Color is borrowed

palette

You cannot assume a dark background, truecolor, working dim/bold/italic, or that green and red are distinguishable.

Response: ansi 16 colors is the default. mono and NO_COLOR work. Status never depends on color alone. Light and dark frames are both golden-tested. Bold marks a verdict, not a hue.

5. Input is raw bytes

keys

In raw mode Ctrl-C and Ctrl-Z are keys, not signals. Alt, F-keys, mouse and Ctrl-Shift combinations are not portable. Esc and Alt share a prefix.

Response: handle Ctrl-C and Ctrl-Z explicitly, restore the terminal first. No required Alt or F-key binding. Short Esc timeout. Bracketed paste sends text to search, never to the action registry. Keymap is rebindable. Mouse is optional in T4.

6. Output is a shared resource

screen

The alternate screen has no scrollback. A crash can leave raw mode on. Clipboard (OSC 52) and synchronized output are disabled in some terminals and multiplexers.

Response: alternate screen, hidden cursor, a Drop guard, a panic hook, and SIGTERM/SIGHUP restore. Synchronized output only when supported. --render-once and copy are the export paths. OSC 52 has a visible fallback that prints the text.

7. Text is untrusted

security

You cannot render pacman, yay, aurto, .SRCINFO or file names raw. ESC/OSC can move the cursor, set the title, write the clipboard or forge a hyperlink. Bidi controls can reorder a path.

Response: one sanitize_cell gate. Strip C0/C1/DEL, ESC, bidi controls, ZWJ and variation selectors. Expand tabs. Replace unprintable bytes with ?. Truncate by display width. Raw child output never reaches the frame.

8. Animation is a budget

motion

You cannot promise 60 fps, smooth particles or low latency over SSH and tmux. Motion can lie about state.

Response: 10 to 15 fps only while a captured fetch runs. Cached nodes never animate. The ready set is a frontier, not a queue: parallel roots may run together and a join waits for every required edge. The tree updates in place; there are no particles and no fake install animation. --no-motion and a config key. Motion is never the only carrier of state. No idle tick.

01

          
Read-only by default
Start, refresh, search, inspect and quit write nothing. No state file, no cache, no pacman database. The test compares package state and cache files before and after.

        

        

          
02

          
Actions are the only mutations
Fetch, install, clean and pacdiff come from one registry. The keymap, footer, palette and help read the same entry. A disabled action stays visible with its reason.

        

        

          
03

          
Fetch is captured, installed is attached
Fetch streams real lines and shows the gate checklist. Install suspends the TUI, restores the terminal, runs yay -Syuu with inherited stdio, then repaints from a fresh snapshot. No --noconfirm, ever.

        

        

          
04

          
No partial install from the list
The Updates panel has no per-row install. Installing one package while the rest of the sync is newer is the partial-upgrade footgun. The action is always the whole plan.

        

        

          
05

          
Clean is a dry run until confirmed
The panel shows the same plan clean prints. Confirm names the item count and bytes, and the exact command. Apply runs attached through sudo <current_exe> clean --apply and warns that sudo drops AUR_PREFETCH_*.

        

        

          
06

          
No gate is softened
News cannot be verified, so it is an attestation, not a check. Missing trust means everyone is trusted, so it requires a second confirm. A failed list is not "nothing pending". A missing fact is shown as missing.

What is still open, and stays visible

      

        
Held is not parsed
IgnorePkg and IgnoreGroup are not read yet, so the UI does not draw a held state. An absent fact beats an invented badge.

        
Signature validity needs gpg
The .sig file proves presence, not validity. Show present, missing or unknown, never "valid" without a check.

        
AUR edges are local-only
Before a build, runtime and build deps are unknown. Solid means local metadata agrees; dashed ? means unknown. No network in v1, no inferred edges.

        
Timeline needs room
The compact tree works at 80×24. The optional timeline needs 120×40; below that it is not offered, and the tree is the screen.

        
Doctor is text-only
The collector exists in the CLI. The panel is v2 and says so until then.

        
Online edges are opt-in
One yay -Si batch, LC_ALL=C, timeout, in-memory TTL, failure keeps local facts. Never the default.
