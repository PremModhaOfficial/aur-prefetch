The graph should move like work, not like a screensaver

nom animates a tree by redrawing state. The next step is animation that encodes causality and time: only edges carrying work flow, the critical path glows, the future is a ghost, and a failure freezes into a repair card. Five sketches, one hybrid.

The bar: nom's tree is the best passive progress display in the terminal. It is passive, Nerd-Font/colour bound, and it cannot show duration, the critical path, or a repair. The hybrid below is the answer: a scrubbable time-space DAG.

What makes it more awesome than nom
  • Time is an axis, not a timer. Future work is a ghost; the now-line is a camera; the critical path is the lit route.
  • Only real work flows. A particle on an edge means the edge is carrying data now. Everything else is still.
  • Failure freezes the graph. The failed node turns red, downstream nodes go blocked, and a repair card replaces the status line.
  • Scrub it. Pause and rewind the run. A post-mortem becomes a replay, not a log crawl.
  • Focus follows the bottleneck. The active node expands; completed branches recede. The camera does the attention management.

Scores are design judgments, not an independent audit. The canvas is a design sketch. The real TUI would use braille/ANSI cells at 10–15 fps with an ASCII fallback; the motion budget is one pulse per active edge, not a particle system per frame. Nothing here runs pacman or writes state.
