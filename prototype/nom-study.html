05 / T2 order

      

        
Seven steps, in dependency order

        

          This is the order for implementation, not a checklist of ticked work.
          Nothing here is implemented in this pass.
        

      

    

    

      

        
01

        

          
Tree model

          
Read PackageView.depends (report.rs:145, filled at
          progress.rs:126). Add installed-only dependency nodes so every edge
          has two endpoints. Dedupe by node id. Mark required and display-only edges. No
          second update collector.

          
accept: diamond fixture has one row per package; an
          installed-only dependency appears once; an unknown edge never gates.

        

      

      

        
02

        

          
Frontier wiring

          
Feed GraphState from src/frontier.rs. Seed cached and
          built artifacts as NoWork, held packages as Excluded, and
          live rows from the fetch stream. A join waits for every required edge. Parallel
          roots are a set.

          
accept: diamond and two-root tests pass through the
          renderer; no state changes without an observation and evidence.

        

      

      

        
03

        

          
Real progress bars

          
Use the nom geometry: left_width = max 60, bar cells
          = width - 2 - left_width - 6, percent %5.1f%%, right edge
          fixed. Draw ■ ◧ □ in unicode and # -  in ASCII. Source
          bytes from the fetch stream or a cache .part file.

          
accept: known bytes produce an exact bar; an unknown total
          produces no bar and no invented percentage.

        

      

      

        
04

        

          
Layout and viewport

          
Adopt the bottom-up tree, ┏━/┃/┣━━━/┗━ ∑,
          the grouped headers, the 13-node window at 40 rows, and the ⋮ marker.
          Never hide a running or failed node. Print one node once.

          
accept: 120×40 and 80×24 goldens; a 200-package fixture
          keeps every running and failed node visible.

        

      

      

        
05

        

          
ANSI-16 palette

          
Blue pending and branches, yellow running and downloads, green done, magenta
          host, grey dim time and waiting for, bright cyan receipt, red failure.
          Bold counts. Glyph and text always carry the state too. NO_COLOR and
          --ascii keep the same text.

          
accept: colour snapshots plus a no-colour frame with
          byte-identical stripped text.

        

      

      

        
06

        

          
Live loop

          
60 ms floor while a task runs, wake on state change, 1 s heartbeat for elapsed
          time. Keep the alternate screen, the Drop restore and the panic hook.
          Redraw the tree block, not the whole screen.

          
accept: pty run counts redraws and proves the floor and
          heartbeat; an idle tree does not redraw; terminal restored on every exit path.

        

      

      

        
07

        

          
Final receipt

          
After restore, print the finished tree summary and a receipt to the normal
          screen. nom gives Finished at HH:MM:SS after <duration>; nh gives
          the changed/added/paths/size/diff idea. For install, print the pacdiff and reboot
          checks and the next command. No raw child output.

          
accept: receipt golden, exit code preserved, every line
          comes from a collected fact.
