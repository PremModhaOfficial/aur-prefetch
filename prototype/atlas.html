The claimed 10/10, screen by screen

The harness claimed 10/10. Two independent clean-context audits scored the same artifacts at 6.0 and 5.1 mean — 4.7 conservative, 2.0 floor: HIE 6 · DEN 8 · CRF 5 · DSC 4 · KEY 2 · SAF 3 · STH 6 · ACC 7 · EXT 4 · ONB 2. The dossier shows the design and the gap.

Read this before the score: the 10/10 is a property of design.json, not of these frames. Both auditors found the same failures: screens that start with tables, a palette that omits actions and collides, gates that do not mirror install.rs, no first-run or per-screen state frames, and an ASCII map missing ·/…. States

Every screen has a state for the awkward cases

The rubric asks every screen for empty, loading, error and blocked, plus stale and unavailable where they apply. These are the dashboard's copies; each screen has its own.

empty

No pending updates. Last fetch 4m ago; last install 9d ago. Still shows disk, timer and trust.

ONB 1

loading

Keep the last values, dim them, spin only the section header. Never a blank panel.

ONB 1, STH 2

error

pacman -Qu failed (exit 2): database error. Retry; other sections stay usable.

STH 1, ONB 5

blocked

pacman is running. Wait for it; the lock is never removed for you.

ONB 3, SAF 1

stale

Cache sizes measured 6m ago; marked stale after two intervals. Not presented as fresh.

STH 2

unavailable

AUR updates unavailable: yay not found. Not '0 pending'.
