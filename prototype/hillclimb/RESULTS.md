## What each iteration changed

1. **STH** — `Section` enum with Ready/Failed/NotCollected and timestamps; partial-upgrade drift; slow-section staleness; unknown/unavailable rules; post-install fields; activity argv/exit/gate.
2. **ACC** — complete ASCII map (borders, gauges, arrows, checkboxes, markers); colour never alone; 80×24/120×40 fit; linear tty-exempt `--render-once` with a fixed clock; reduced motion; absolute timestamps.
3. **EXT** — panel registry, four-step add-a-panel recipe, golden tests; one action source; theme registry; line config; `Section` enum.
4. **SAF** — gates mirror `install.rs` exactly; missing trust needs a second confirm; empty trust refuses; news is session-only; failure/disk-full/pacdiff/kernel/reboot post-install; clean dry-run, absolute exe, env warning.
5. **KEY** — precedence modal > panel > global; fetch `F`, clean `x`, filter `f`, clear `c`; complete list and modal keys; rebind validation.
6. **DSC** — every action has `enabled_reason`; palette lists all; footer/help derive from the registry; empty state names the next command.
7. **ONB** — every screen defines empty/loading/error/blocked; first run explains the split; install teaches news/trust/reboot; `--render-once` demo.
8. **CRF** — one token set, no raw colours, ellipsis truncation, ansi/dark/light/mono.
9. **HIE** — every screen opens with a verdict/summary; one primary action; partial-upgrade drift block; help teaches the model.
10. **DEN** — caches gains policy/action, activity gains source, settings keeps setting/value/source.

## Adversarial audit

The harness says 10/10. Two independent clean-context audits re-scored the same
artifacts at **6.0 and 5.1 mean — conservative 4.7, floor 2.0**:
`HIE 6 · DEN 8 · CRF 5 · DSC 4 · KEY 2 · SAF 3 · STH 6 · ACC 7 · EXT 4 · ONB
2`. The weak checks and evidence are in
[`AUDIT.md`](AUDIT.md). The 10/10 is a harness result; the audits are the honest
limit.

## Caveat

This is a rubric target, not a user study. The checks read a design model, not
shipping Rust code. Atlas is shown separately from the shipped ranking and is
not claimed to beat lazygit in practice.
